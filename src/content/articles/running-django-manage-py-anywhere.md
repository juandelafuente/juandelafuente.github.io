<p>Sometimes when dealing with Django Python projects you want to be able to run <em>manage.py</em> from anywhere.</p><p>Let’s go for a step by step demo. Basically, we create an <em>entry_point</em> in the package <em>setup.py</em> that runs the code inside the <em>manage</em> function included in the <em>__init__.py</em> file.</p><p><strong>Directory for the demoapp:</strong></p><pre>mkdir /home/jfuente/proyectos/demoapp</pre><p><strong>Create a virtualenv</strong>:</p><pre>mkvirtualenv demoapp -a /home/jfuente/proyectos/demoapp/</pre><p><strong>Install Django package inside the virtualenv:</strong></p><pre>(demoapp)… pip install Django</pre><p><strong>Start a project named demoapp:</strong></p><pre>(demoapp) django-admin startproject demoapp</pre><p><strong>Create/update the __init__.py inside the project path with content:</strong></p><iframe src="" width="0" height="0" frameborder="0" scrolling="no"><a href="https://medium.com/media/864a4fa52159223bd3a6dd8171dc11b3/href">https://medium.com/media/864a4fa52159223bd3a6dd8171dc11b3/href</a></iframe><p><strong>Now inside the package setup file (setup.py):</strong></p><iframe src="" width="0" height="0" frameborder="0" scrolling="no"><a href="https://medium.com/media/eff6ddf786e5eff7d3760867bc554ae1/href">https://medium.com/media/eff6ddf786e5eff7d3760867bc554ae1/href</a></iframe><p>Now you just have to install the package in develop mode to test if everything works…</p><pre>python setup.py develop</pre><p>Then run the manage.py command by running the demoapp project like.</p><pre>demoapp</pre><p>and it’s done..</p><figure><img alt="demoapp running manage.py as entry_point in setup.py" src="https://cdn-images-1.medium.com/max/654/1*kqLU30mwZ7tvgLkPvH5owg.png" /><figcaption>demoapp version and test commands</figcaption></figure><p>I’m sure there will be better ways, but that’s the one that works for me.</p><p>What’s yours?</p>
