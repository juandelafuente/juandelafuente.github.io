<p>Sometimes when dealing with Django Python projects you want to be able to run <em>manage.py</em> from anywhere.</p><p>Let’s go for a step by step demo. Basically, we create an <em>entry_point</em> in the package <em>setup.py</em> that runs the code inside the <em>manage</em> function included in the <em>__init__.py</em> file.</p><p><strong>Directory for the demoapp:</strong></p><pre>mkdir /home/jfuente/proyectos/demoapp</pre><p><strong>Create a virtualenv</strong>:</p><pre>mkvirtualenv demoapp -a /home/jfuente/proyectos/demoapp/</pre><p><strong>Install Django package inside the virtualenv:</strong></p><pre>(demoapp)… pip install Django</pre><p><strong>Start a project named demoapp:</strong></p><pre>(demoapp) django-admin startproject demoapp</pre><p><strong>Create/update the __init__.py inside the project path with content:</strong></p><script src="https://gist.github.com/juandelafuente/f80dc53e64f5d5775ea8225b6a2f69eb.js"></script><p><strong>Now inside the package setup file (setup.py):</strong></p><script src="https://gist.github.com/juandelafuente/078419ceef378ea2f88e1fd6c00f1d9a.js"></script><p>Now you just have to install the package in develop mode to test if everything works…</p><pre>python setup.py develop</pre><p>Then run the manage.py command by running the demoapp project like.</p><pre>demoapp</pre><p>and it’s done..</p><figure><img alt="demoapp running manage.py as entry_point in setup.py" src="/images/articles/running-django-manage-py.webp" /><figcaption>demoapp version and test commands</figcaption></figure><p>I’m sure there will be better ways, but that’s the one that works for me.</p><p>What’s yours?</p>
