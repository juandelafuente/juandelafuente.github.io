pubDate: 2021-12-24

<p>In order to use Virtualenv with your Ubuntu OS you need to follow the next steps, at least, these are my notes..</p><p><strong>At the beginning there was nothing…</strong></p><figure><img alt="" src="/images/articles/virtualenv-ubuntu-version-and-packages.webp" /><figcaption>Ubuntu version and no virtualenv packages</figcaption></figure><p>Ubuntu release is 20.04.3</p><pre>lsb_release -a</pre><p>No deb virtualenv packages</p><pre>dpkg -l | grep virtualenv</pre><p>No pip3 virtualenv packages</p><pre>pip3 freeze | grep virtualenv</pre><p>Now with apt we install this packages (virtualenv and virtualenvwrapper)</p><pre>sudo apt install virtualenv virtualenvwrapper</pre><p>As a result this packages are installed..</p><figure><img alt="" src="/images/articles/virtualenv-ubuntu-20.04.3.webp" /><figcaption>Installed packages</figcaption></figure><p>If you want easy access to run <strong>virtualenv</strong> commands via <strong>virtualenvwrapper</strong> it is recommended to edit your <em>.bashrc</em> file and include at the end these three lines:</p><pre>export VIRTUALENVWRAPPER_PYTHON=/usr/bin/python3<br>export WORKON_HOME=$HOME/.virtualenvs<br>. /usr/share/virtualenvwrapper/virtualenvwrapper.sh</pre><p>Now if you run your <em>bash</em> command, virtualenvwrapper commands would be available.</p><p>What I usually do is, create the folder project, then create a <em>virtualenv</em> with the same name.</p><pre>mkdir /home/jfuente/proyectos/myprojectname/</pre><pre>mkvirtualenv myprojectname -a /home/jfuente/proyectos/myprojectname/</pre><p>If everything has worked fine, you’ll see the virtualenv name in the terminal</p><pre>(myprojectname) jfuente@zombie:~/proyectos/myprojectname$</pre><p>Now you can run the command <strong>workon myprojectname</strong> to activate the virtualenv, and <strong>deactivate</strong> to exit the environment.</p><p>When creating the virtualenv, you can use the <strong>parameter -p</strong> to set the Python version for the environment.</p><p>If you have python2 installed and you want to use it for a virtual environment you should do.</p><pre>mkdir /home/jfuente/proyectos/mypy2project</pre><pre>mkvirtualenv mypy2project -a /home/jfuente/proyectos/mypy2project/ -p /usr/bin/python2.7</pre><p>Other interesting commands are <strong>lsvirtualenv</strong> and <strong>rmvirtualenv</strong>.</p><p>More on <a href="https://twitter.com/jdelafuente">https://twitter.com/jdelafuente</a></p>
