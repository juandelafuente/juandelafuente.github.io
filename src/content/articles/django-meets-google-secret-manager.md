<h3>Django meets Google SecretManager</h3><p>One of the most common things you need to manage when developing an application is .. Where the hell should I keep my passwords? and not just where to keep them, how to access them in a secure way?.</p><p>You can find different tutorials on using GCP Secret Manager API with Python but here you can find an example of handling Django settings.py passwords or certs querying GCP Secret Manager API.</p><p>First of all you need to enable the SecretManager API.</p><figure><img alt="Secret Manager API enabled" src="/images/articles/django-secret-manager.webp" /><figcaption>Secret Manager API Enabled</figcaption></figure><p>Then you need to create your secrets, upload your files, set versions and enable the secrets.</p><p>Having all that configured, let’s go to the code..</p><p>You need to have installed at least the <em>google-cloud-secret-manager python package</em></p><pre>pip install google-cloud-secret-manager</pre><p>Wherever you what to use it you need to import the module in your code:</p><pre>from google.cloud import secretmanager</pre><p>In my case I have created two different functions, one to get the recovered decoded utf8 string directly to the settings.py file and another for donwload and write to disk the ssl certificates for database secure access.</p><p>The function below <em>get_secret</em> gets <em>secretname</em> as parameter, then with values from the <em>settings</em> file as <strong>PROJECT_ID</strong> creates the full_name of the secret. With this information calls the secretmanager client and decodes the data payload as utf8.</p><p>This final value, the decoded password, is used in the settings.py file, examples are provided at the end.</p><script src="https://gist.github.com/juandelafuente/1384273e57a7d1e98a3ffb2f38edd64f.js"></script><p>I have configured Postgresql instances secure access with SSL certificates so I need to download them in order to connect to the db from the instances.</p><p>To do so, I call <em>get_secret</em> inside another function that stores the secret, the ssl certificate here, and set the file permisions on the instance filesystem.</p><p>This function requires the <em>secretname</em> and <em>filename</em> as parameters.</p><script src="https://gist.github.com/juandelafuente/9b7fa34df025c8332fd4a314653c0186.js"></script><p>Example:</p><p>In the settings file for getting the database password you can use in the DATABASES dictionary for the key PASSWORD these:</p><pre>‘PASSWORD’: ‘%s’ % (get_secret(‘mysecretkey’)),</pre><p>where <em>mysecretkey</em> is the name of the password in Google SecretManager.</p><p>Remember to import the functions <em>get_secret </em>and <em>get_secret_and_write_to_file</em> in the <em>settings</em> file to use it.</p><p>I hope you find it usefull.
